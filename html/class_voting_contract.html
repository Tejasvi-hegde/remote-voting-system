Detailed Description

VotingContract — Hyperledger Fabric Smart Contract

This chaincode runs on every peer node. All functions that write to the ledger create a new block. All reads use CouchDB as the state database (for rich queries).

Ledger key structure: VOTE_{voterID} → vote record (one per voter) COUNT_{constituencyID}_{candidateID} → running vote tally TX_{transactionID} → transaction metadata
