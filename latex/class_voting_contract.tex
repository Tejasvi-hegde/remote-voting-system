\doxysubsection{Detailed Description}
\doxylink{class_voting_contract}{Voting\+Contract} — Hyperledger Fabric Smart Contract

This chaincode runs on every peer node. All functions that write to the ledger create a new block. All reads use Couch\+DB as the state database (for rich queries).

Ledger key structure:\+ VOTE\+\_\+\{voter\+ID\} → vote record (one per voter) COUNT\+\_\+\{constituency\+ID\}\+\_\+\{candidate\+ID\} → running vote tally TX\+\_\+\{transaction\+ID\} → transaction metadata
